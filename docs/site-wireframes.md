# 東京リーグ リニューアル ワイヤー案

最終更新: 2026-03-22 JST

## 目的

- 現行サイトの情報を整理して、新サイトの公開画面構成を定義する
- ニュースと試合結果を管理画面から更新しやすい導線にする
- ドメイン移行後も迷わず運用できる構成にする

## グローバル構成

### 共通ヘッダー

- ロゴ
- ナビゲーション
  - トップ
  - 東京リーグについて
  - 試合情報
  - ニュース
  - 参加チーム
  - 資料ダウンロード
  - お問い合わせ
- 重要導線
  - 最新試合結果
  - Instagram

### 共通フッター

- 東京リーグ概要
- お問い合わせフォーム
- 規約・規約細則
- ダウンロード
- SNSリンク
- 著作権表記

## サイトマップ

1. トップ `/`
2. 東京リーグについて `/about`
3. 試合情報トップ `/competitions`
4. 大会詳細 `/competitions/[competitionSlug]`
5. リーグ結果詳細 `/competitions/[competitionSlug]/divisions/[divisionSlug]`
6. ニュース一覧 `/news`
7. ニュース詳細 `/news/[slug]`
8. 参加チーム一覧 `/teams`
9. チーム詳細 `/teams/[slug]`
10. 資料ダウンロード `/downloads`
11. お問い合わせ `/contact`

## 画面別ワイヤー

### 1. トップ `/`

目的:
新着情報と試合結果への導線を最短で見せる

構成:

```text
+------------------------------------------------------+
| Header                                               |
+------------------------------------------------------+
| Hero                                                 |
|  - 東京リーグのコピー                                |
|  - 次回大会やリーグ概要                              |
|  - CTA: 試合結果を見る / ニュースを見る              |
+------------------------------------------------------+
| Latest News                                          |
|  - 最新3〜5件                                        |
|  - 各記事の公開日、カテゴリ、タイトル                |
+------------------------------------------------------+
| Latest Results                                       |
|  - 直近の大会                                        |
|  - リーグ別の結果導線                                |
|  - CTA: 大会詳細へ                                   |
+------------------------------------------------------+
| About Tokyo League                                   |
|  - 概要文                                            |
|  - CTA: 東京リーグについて                           |
+------------------------------------------------------+
| Teams Preview                                        |
|  - チームロゴまたはカード                            |
|  - CTA: 参加チーム一覧                               |
+------------------------------------------------------+
| Downloads / Instagram                                |
+------------------------------------------------------+
| Footer                                               |
+------------------------------------------------------+
```

主要要素:

- ニュースは日付とカテゴリを表示
- 試合結果は「大会名」「リーグ名」「更新日」を表示
- 固定バナーは極力減らし、更新情報が前面に出る構成にする

+------------------------------------------------------+

+------------------------------------------------------+

### 3. 試合情報トップ `/competitions`

目的:
大会一覧と年度アーカイブへの入口を作る

構成:

```text
+------------------------------------------------------+
| Page Title                                           |
+------------------------------------------------------+
| Current Season Summary                               |
|  - 開催中または最新年度の大会一覧                    |
+------------------------------------------------------+
| Competition Cards                                    |
|  - 大会名                                            |
|  - 年度                                              |
|  - 開催期間                                          |
|  - 参加リーグ数                                      |
|  - CTA: 詳細を見る                                   |
+------------------------------------------------------+
| Archive Filter                                       |
|  - 年度で絞り込み                                    |
+------------------------------------------------------+
| Download Links                                       |
|  - 要項PDF                                           |
+------------------------------------------------------+
```

主要要素:

- 大会単位で整理する
- 山藤杯のような別大会も同一構造に載せられるようにする

### 4. 大会詳細 `/competitions/[competitionSlug]`

目的:
大会単位の概要とリーグ一覧を見せる

構成:

```text
+------------------------------------------------------+
| Competition Hero                                     |
|  - 大会名                                            |
|  - 年度 / 回次 / 開催期間                            |
|  - 大会概要                                          |
+------------------------------------------------------+
| Attached Files                                       |
|  - 要項 / 組み合わせ / 注意事項                      |
+------------------------------------------------------+
| Division Navigation                                  |
|  - Aリーグ / Bリーグ / Cリーグ...                    |
+------------------------------------------------------+
| Division Cards                                       |
|  - リーグ名                                          |
|  - 参加チーム数                                      |
|  - 最終更新日                                        |
|  - CTA: リーグ結果を見る                             |
+------------------------------------------------------+

+------------------------------------------------------+
```

備考:

- 大会に関連するニュースを下部に出せるようにする
- 公開前の大会は非表示にできる必要がある

### 5. リーグ結果詳細 `/competitions/[competitionSlug]/divisions/[divisionSlug]`

目的:
順位表と試合結果を見やすく掲載する

構成:

```text
+------------------------------------------------------+
| Breadcrumb                                           |
+------------------------------------------------------+
| Division Header                                      |
|  - 大会名 / リーグ名 / 最終更新日                    |
+------------------------------------------------------+
| Standings Table                                      |
|  - 順位 / チーム / 試合数 / 勝点 / 勝敗 / 得失点     |
+------------------------------------------------------+
| Match Results                                        |
|  - 日付                                              |
|  - 対戦カード                                        |
|  - スコア                                            |
|  - 会場                                              |
|  - 備考                                              |
+------------------------------------------------------+
| Division Teams                                       |
|  - 所属チーム一覧                                    |
+------------------------------------------------------+
| Download / Print                                     |
+------------------------------------------------------+
```

重要方針:

- 試合結果は画像ではなくデータ表示を基本にする
- 必要なら後からPDF出力機能を追加する
- 順位表は手入力にも自動計算にも対応できる設計にする

## ナビゲーション方針

- 「試合情報」は大会一覧まで1クリックで到達できること
- 「ニュース」はトップから直接一覧と個別記事へ遷移できること
- 固定情報は `東京リーグについて` に集約してナビゲーションを軽くする

## モバイル方針

- トップではニュースと試合結果を最優先表示
- 表組みが横長になる順位表は横スクロール対応
- リーグ切り替えはタブより縦並びリンクを優先検討
