# 管理画面 未実装・追加実装候補リスト

更新日: 2026-06-25 JST

納品マニュアル作成時点で、実装コードと画面を照合して洗い出した項目です。後続実装時はこの一覧を起点に、優先度順に対応します。

## 対応済み

| 対象 | 対応内容 | 備考 |
| --- | --- | --- |
| 年度 | 折りたたみ式の追加・編集・削除・現在年度切替UI | 大会が紐づく年度は削除不可 |
| 大会 | 全大会一覧、専用編集ページ、削除、公開日・表示順・期間の管理 | 終了済み大会も一覧から編集可能。関連データがある大会は削除不可 |
| 大会・リーグ | 表示順の自動設定 | 新規追加時に未入力なら同一年度・大会内の末尾へ自動設定 |
| リーグ | 大会別ページでの編集、削除、状態・説明・表示順の管理 | 所属チーム、試合、順位表、担当割当が紐づくリーグは削除不可 |
| チーム | Instagram URL編集 | URL、@アカウント名、アカウント名のみの入力に対応 |
| チーム削除 | 削除前の参照先表示 | 所属リーグ、試合、順位表の参照数を一覧で確認可能 |
| お知らせ | 本文画像管理 | アイキャッチとは別に本文画像を最大10枚登録・削除可能 |
| 順位表 | 個別行削除 | 登録済み順位表の確認欄から削除可能 |
| 順位表 | 入力クリア、登録値への復帰 | 保存前の入力内容を一括で戻せる |
| 順位表 | 行追加 | 結果管理から未所属の公開チームを順位表へ追加し、リーグ所属にも同期 |
| 順位表 | 星取表画像の自動生成 | 登録済み試合からSVGを生成し、表示・保存・結果画像への登録が可能 |
| 順位表 | 登録内容の表形式表示 | 順位、チーム、試合、得失点差、勝点、削除操作を一覧表示 |
| 試合 | 登録済み試合の入力レイアウト改善 | 長いチーム名でもホーム・アウェイ・得点欄が重ならない列構成 |
| 試合 | Excel一括入稿 | 「管理表」シート入り.xlsxをプレビューし、新規試合の追加・同一対戦の更新に対応 |
| 管理者 | 編集画面、ロール変更確認 | 登録済み担当者欄から表示名・ロールを更新可能 |
| 管理者 | 有効化・無効化 | 無効化した担当者は管理画面へログイン不可 |
| 問い合わせ先 | 受信先メール・有効/無効・ロール変更 | 担当割当画面の `CONTACT` ロールで管理。管理画面へのログイン権限なし |
| 資料 | 公開URL確認強化 | 一覧でアップロード済みファイル名と公開URL確認リンクを表示 |
| 理事会 | メンバー追加・編集・削除 | Owner専用。公開サイトの「東京リーグについて」ページへ反映 |
| 監査履歴 | 更新履歴一覧 | Owner専用画面でニュース、大会、試合、資料などの直近作成・更新履歴を確認可能 |

## 優先度高

現時点で納品前に必須対応したい高優先度項目はありません。

## 優先度中

| 対象 | 現状 | 追加したい操作 | 備考 |
| --- | --- | --- | --- |
| 大会関連ファイル | データモデルのみ | 大会への要項・組み合わせ・結果PDF紐付け | `CompetitionFile` モデルはあるが管理UIなし |
| 担当権限 | `担当リーグ編集` として一括付与 | 結果編集、順位編集、リーグ管理の細分化UI | enum は存在するが画面では `DIVISION_MANAGER` に集約 |
| チーム削除 | 参照中は削除不可、削除前の参照先表示 | 代替チーム移管 | 現状は削除前に所属リーグ、試合、順位表の参照数を表示 |
| 資料 | 新規・編集・削除、公開URL確認あり | ファイル削除なしでメタ情報のみ更新 | 一覧と編集画面で現在資料を確認可能 |

## 優先度低・将来検討

| 対象 | 現状 | 追加したい操作 | 備考 |
| --- | --- | --- | --- |
| 固定ページ | データモデルのみ | About / Contact 等の本文編集 | `Page` モデルはあるが管理UIなし |
| 会場 | 試合入力時に自動作成 | 会場マスタ編集・削除 | `Venue` モデルはあるが管理UIなし |
| 非公開化の一括操作 | 個別操作中心 | 複数選択・一括公開/非公開 | 登録量が増えた場合に有効 |

## 実装時の注意

- Ownerのみがグローバル管理機能を操作できる現在の権限方針は維持する。
- Editor向けには割当済みリーグ以外が見えない、保存できない制御を継続する。
- 削除系は既存の `ConfirmForm` と参照チェックを使い、誤削除を防ぐ。
- 年度・大会・リーグの削除は、紐づくリーグ、試合、順位、資料、担当割当の参照関係を確認してから実装する。
- 画面追加後は、納品マニュアルの該当ページも更新する。
